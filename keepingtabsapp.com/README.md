# keepingtabsapp.com

Source of the pages served from `/public_html` on the Bluehost account for
keepingtabsapp.com. Upload through cPanel's File Manager (one file per upload,
"Overwrite existing files" ticked). Bluehost's edge cache holds HTML for two
hours, so a change shows at the plain address only after that, or at once with
a `?v=` query added.

The root of this repository is what GitHub Pages serves at
pyrokinesisltd.github.io/keeping-tabs-legal/, which now only forwards here.
